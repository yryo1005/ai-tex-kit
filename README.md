# 文書作成に関する規約
本リポジトリは，AIによるLaTeX文書および学術論文の作成・改訂に用いる共通規約とテンプレートを提供する．

---

# 論文構成
論文・予稿を作成する際は，過去のユーザーの指示 `@.orders/` や，AIエディタが作成したプログラム `@programs/` とレポート `@.reports/` ，プログラムの出力 `@outputs`を参考にする．

# 論文のサンプル
過去に私が書いた論文・予稿のサンプルです．
章立てや単語の選択，文章の記法のサンプルにしてください．
ただし，サンプルに記載された研究内容，実験条件，結果等を新たな文書へそのまま流用してはならない．
ページ数の指定がある場合は，特に指定がない限り，内容および構成が類似するサンプルを参考にして全体の分量を調整する．
特に，大喜利生成AIに関する論文は類似した内容でページ数の異なる論文および予稿を含むため，ページ数に応じた文章量，章構成および図表数の調整方法を参考にする．

# AIエージェントとの連携
本プロジェクトでは，`.ai/ai-agent/`のAIエージェントが，作成した論文・予稿の内容をGemini API
へPDFとして入力し，改善提案やプロンプトとの不一致の指摘を検討する場合がある．
`ai-tex-kit`自体の役割は，論文・予稿の作成規約とテンプレートの提供であり，AIエージェントの
役割（次の指示の検討）とは異なるため，両者を混同しない．

- `main.tex`等を編集した場合は，`@.ai/ai-dev-kit/documentation.md`の規約に従い，必ず
  `latexmk`で最新のPDFを再生成し，リポジトリ内に最新のPDFを保持する．
- `.reports/report_{k:03}.md`には，作成した論文・予稿の対象（投稿先，ページ数制限，締切等）や，
  未解決の指摘事項を明記し，AIエージェントが次の指示を検討する際に参照できるようにする．

# ディレクトリ構造の例
```text
./
├── .ai/ 			                # AIコーディングへの指示をまとめたディレクトリ
│   ├── ai-agent/ 		            # AIエージェントのプログラムのリポジトリ(サブモジュールの場合も，プロジェクト内へ直接実装する場合もある)
│   │   ├── core/		            # 全てのAIエージェントに共通する基盤
│   │   ├── research/		        # 研究に関するAIエージェント
│   │   ├── machine_learning/	    # 機械学習に関するAIエージェント
│   │   ├── development/	        # 開発に関するAIエージェント
│   │   ├── documentation/	        # 文書作成に関するAIエージェント
│   │   └── slide/		            # スライド作成に関するAIエージェント
│   ├── ai-dev-kit/		            # プログラムの作成指示，便利関数のリポジトリ(サブモジュール)
│   │
│   ├── ai-tex-kit/		            # 文書の作成指示，テンプレートのリポジトリ(サブモジュール)
│   │   ├── samples/		        # 過去の論文・予稿のサンプル
│   │   ├── templates/		        # TeXのテンプレート
│   │       ├── ja_paper/		    # 和文のフォーマット
│   │       │   ├── main.tex        # latexでコンパイルするソース
│   │       │   ├── sections/       # 論文の章ごとに分けられたソースをまとめたディレクトリ
│   │       │   └── figures/        # 論文の画像をまとめたフォルダ
│   │       └── en_paper/		    # 英文のフォーマット
│   │
│   └── ai-pptx-kit/		        # スライドの作成指示，テンプレートのリポジトリ(サブモジュール)
│
├── paper/                          # AIコーディングが作成した論文（ディレクトリ名は適時変更する）
│   ├── main.tex
│   ├── sections/
│   │   ├── 01_introduction.tex
│   │   ├── 02_related_work.tex
│   │   └── ...
│   └── figures/
│
├── .venv_{環境名}/		            # 仮想環境
├── .logs/			                # AIエージェントのログを保持するディレクトリ
├── .orders/		                # AIコーディングへの指示を保持するディレクトリ
│   ├── order_001.md                # 人間が作成したAIコーディングへの指示
│   └── order_002.md
│
├── .reports/		                # AIコーディングのレポートを保持するディレクトリ
│   ├── report_001.md               # AIコーディングが作成した実行結果のサマリー
│   └── report_002.md
│
├── programs/		                # AIコーディングが作成したプログラムを保持するディレクトリ
├── outputs/		                # AIコーディングが作成したプログラムの出力を保持するディレクトリ
├── .gitignore		                # tokens.jsonを追加する
├── document.md		                # リポジトリの説明が書かれたmdファイル
├── tokens.json		                # APIトークンが格納されたjsonファイル
└── requirements_{環境名}.txt	    # Pythonのライブラリを記述したtxtファイル

```
